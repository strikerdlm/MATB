# Glosario para exposición y preguntas

| Sigla/término | Definición y uso |
|---|---|
| ASTRA | Aerospace Simulation Training Research Analogs; proyecto de misiones análogas terrestres. |
| MATB | Multi-Attribute Task Battery; batería de tareas de atributos múltiples. |
| OpenMATB | Implementación abierta de MATB descrita por Cegarra et al. (2020); distinguirla de NASA MATB-II y USAARL MATB. |
| SYSMON | System monitoring; supervisión de sistemas mediante luces e indicadores. |
| TRACK | Tracking; seguimiento compensatorio del cursor. |
| COMM | Communications; tarea de comunicaciones. |
| RESMAN | Resource management; gestión de recursos y depósitos. |
| LOW / MEDIUM / HIGH | Etiquetas de tres condiciones de demanda parametrizadas; su significado depende de parámetros concretos. |
| NASA-TLX | NASA Task Load Index; índice de carga de tarea de la NASA, seis dimensiones subjetivas. |
| RTLX | Raw Task Load Index; media no ponderada de seis ítems completos, reescalada a 0–100 en el contrato vigente. |
| ISA | Instantaneous Self-Assessment; autoevaluación instantánea. |
| KSS | Karolinska Sleepiness Scale; escala de somnolencia de Karolinska. |
| VFC / HRV | Variabilidad de la frecuencia cardíaca / heart rate variability. |
| R–R | Intervalo entre ondas R cardíacas consecutivas; insumo para VFC, sujeto a calidad y procesamiento. |
| DM | Día de misión, numerado desde ingreso. |
| V0–V7 | Ocho visitas previstas por persona. V0 premisión, V1–V6 intramisión, V7 postmisión D+1. |
| D−6 / D−23 | Distancia prevista desde V0 hasta ingreso para ASTRA 1 / ASTRA 2. |
| D+1 | Día posterior al egreso. |
| DIMAE | Dirección de Medicina Aeroespacial. |
| MCC | Mission Control Center; Centro de Control de Misión. |
| CSV | Comma-separated values; formato tabular de registros. |
| SHA-256 | Función de resumen criptográfico; permite contrastar integridad de archivos. |
| Semilla | Valor que fija una generación pseudoaleatoria reproducible junto con parámetros y versión. |
| Manifiesto | Archivo que documenta condición, parámetros, procedencia e integridad. |
| Contrabalanceo | Distribución del orden de condiciones entre personas. Distinto de rotación hora/estación. |
| Datos sintéticos | Entradas creadas para comprobación técnica; no observaciones de participantes. |
| Elegibilidad analítica | Cumplimiento de reglas para incluir un registro en un análisis determinado. |

Definiciones coherentes con `notas_data.json`, auditoría técnica A2 y referencias APA [1–6].
