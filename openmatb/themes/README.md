# OpenMATB visual profiles

These JSON profiles are part of the modified OpenMATB runtime distributed in
this repository under the CeCILL v2.1 terms in `../LICENSE`. The original
OpenMATB authorship notices remain in the Python runtime; the versioned visual
profile system and `fac_modern` profile are MATB-FAC modifications.

Each file conforms to the repository's closed
`openmatb-visual-profile-v1` contract. Do not add scenario behavior,
participant identifiers, arbitrary CSS, or executable content. Create and
publish custom profiles through the Research Console so their normalized
SHA-256 and lifecycle are recorded.
